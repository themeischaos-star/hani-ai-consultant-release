# FAQ

## 차트 프로그램과 연동되나요?

아닙니다. 특정 차트 프로그램과 직접 연동하지 않습니다. 스크린샷, PDF, Excel, CSV와 Clipboard를 이용합니다.

## 내 데이터가 개발자에게 전송되나요?

아닙니다. 모든 자료와 Database는 사용자 PC에 저장됩니다. 개발자는 매출, 환자 수, OCR 결과, PDF, Excel 등을 확인하거나 수집할 수 없습니다.

## 왜 Windows 보안 경고가 뜨나요?

Code Signing 인증서가 아직 적용되지 않았기 때문입니다. v1.6.1 배포본은 Microsoft Defender 검사에서 위협 없음을 확인했습니다. 공식 Release와 SHA-256을 확인한 뒤 `추가 정보 → 실행`을 선택할 수 있습니다.

## Mac에서도 사용할 수 있나요?

현재는 Windows 10/11 64-bit 전용입니다.

## AI 분석을 사용하려면 API Key가 필요한가요?

아닙니다. 프로그램은 ChatGPT가 분석하기 좋은 Markdown으로 데이터를 정리합니다. 사용자의 ChatGPT Free 또는 Plus를 이용하므로 OpenAI API Key와 추가 API 비용이 필요하지 않습니다.

## AI가 자동으로 내 데이터를 가져가나요?

아닙니다. 사용자가 `AI 분석`을 선택했을 때만 Markdown이 Clipboard에 복사되고 ChatGPT가 열립니다. 실제 붙여넣기와 전송 내용은 사용자가 확인해야 합니다.

## 어떤 파일을 넣을 수 있나요?

PNG, JPG, JPEG, PDF, XLS, XLSX, CSV를 지원합니다. Clipboard의 이미지, 텍스트, 숫자, 표와 Excel 셀도 붙여넣을 수 있습니다.

## OCR 결과가 틀리면 어떻게 하나요?

OCR 검수 표에서 숫자를 직접 수정하고 저장하면 수정값이 Database에 반영됩니다. 저장 전에 원본과 한 번 비교해 주세요.

## 데이터가 부족해도 분석할 수 있나요?

가능합니다. 현재 보유한 자료를 기준으로 분석하되 데이터 신뢰도와 Data Readiness가 함께 표시됩니다. 장기 분석은 충분한 기간의 누적 자료가 필요합니다.

## 업데이트하면 기존 데이터가 사라지나요?

사용자 데이터는 EXE와 분리된 폴더에 저장됩니다. 일반적인 EXE 교체 업데이트로 삭제되지 않지만, 업데이트 전 Backup을 권장합니다.

## 프로그램은 무료인가요?

현재 Public Release는 무료로 다운로드할 수 있습니다. ChatGPT를 사용할 경우 사용자가 이용 중인 ChatGPT 요금제의 정책이 적용되며 별도의 OpenAI API 비용은 없습니다.


## 자료가 적으면 분석이 중단되나요?

아닙니다. 현재 확보된 Core KPI만으로 분석을 먼저 완료합니다. 더 깊은 분석에 쓸 자료는 선택사항으로만 한 번 안내됩니다.

## 메뉴가 이전과 달라졌나요?

v2.0은 기능을 삭제하지 않고 Dashboard·Analysis·Business Calendar·Reports·Data Center·Settings로 정리했습니다. 기존 고급 기능은 상단 메뉴에서도 계속 사용할 수 있습니다.
