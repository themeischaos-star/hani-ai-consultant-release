# 한의원 AI 경영컨설턴트 v1.7.1 사용설명서

## 1. 설치

1. Public Repository의 최신 Release에서 `hani-ai-consultant-v1.7.1.exe`를 내려받습니다.
2. README에 표시된 SHA-256과 다운로드 파일의 값을 비교합니다.
3. 별도의 설치 과정 없이 EXE를 실행합니다.
4. SmartScreen 경고가 나오면 공식 파일과 SHA-256을 확인한 경우에만 `추가 정보 → 실행`을 선택합니다.

PowerShell에서 SHA-256을 확인하려면 다음 명령을 사용합니다.

```powershell
Get-FileHash .\hani-ai-consultant-v1.7.1.exe -Algorithm SHA256
```

정상 SHA-256:

```text
bb5b468ad433e48ec0e44ad12cab3a7a6c41837e76ba5edb05f9891cb9948e1c
```

## 2. 최초 실행

최초 실행 Wizard에서 프로그램 소개, 입력 자료, 데이터 축적 기간과 사용 흐름을 확인합니다. 한의원명, 대표자명, 개원일과 기본 KPI를 입력하면 자료·보고서·Database·Backup 폴더가 생성됩니다.

최초 입력값은 이후 `환경설정`에서 변경할 수 있습니다. 환경설정에는 자료, 보고서, Database, Backup, 설정 파일의 실제 저장 경로와 `폴더 열기` 기능이 제공됩니다.

## 3. 자료 넣기

다음 방법 중 편한 방식을 사용합니다.

- `파일 선택`: PNG, JPG, JPEG, PDF, XLS, XLSX, CSV
- 드래그앤드롭: 파일을 메인 화면으로 끌어놓기
- `Ctrl+V`: Clipboard 이미지·텍스트·숫자·표·Excel 셀 붙여넣기
- 감시 폴더: 지정 폴더의 새 지원 파일 감지

차트 프로그램과 직접 연동하지 않습니다. 차트 화면을 `Win+Shift+S`로 캡처한 뒤 프로그램에서 `Ctrl+V`를 눌러도 됩니다.

## 4. OCR 수정

이미지나 스캔 PDF는 OCR 후 바로 수정 가능한 표로 표시됩니다.

1. 날짜와 지표명을 확인합니다.
2. 낮은 신뢰도 숫자와 `⚠ 확인 필요` 항목을 우선 확인합니다.
3. 음수, 총매출보다 큰 구성 매출, 급증·급감 등 이상값을 원본과 비교합니다.
4. 틀린 값을 직접 수정합니다.
5. Enter 또는 저장 버튼을 눌러 Database에 반영합니다.

OCR는 입력을 돕는 기능입니다. 최종 기준 데이터는 사용자가 확인한 Database 값입니다.

## 5. 데이터 분석

저장된 Database를 기준으로 다음 항목을 계산합니다.

- 일간·월간·연간 누적
- 평균, 최고, 최저, 증감률, 이동평균과 추세
- 전일·전전일·직전 동일요일 비교
- 전주·전전주·직전 월의 같은 주 비교
- 전월·전전월·작년 동월 비교
- KPI 상태, 목표 달성률과 알림
- 100점 Health Score와 산정 근거
- 경영 시뮬레이션과 3·6·12개월 예측

자료가 적어도 현재 데이터로 분석할 수 있지만 신뢰도와 Data Readiness를 함께 확인해야 합니다. 예측값은 확정 실적이 아닙니다.

## 6. AI 분석

`경영 캘린더`에서는 날짜별 색상으로 평균 이상·평균·평균 이하를 확인할 수 있습니다. 날짜를 선택하면 당시 KPI, Health Score, Timeline, 경영일지와 개선과제 상태가 함께 나타납니다. 전일·직전 동일요일·최근 4주 동일요일 평균·전월·전년 비교는 자동 계산되며, `자동 비교 설정`에서 기준을 추가하거나 제외할 수 있습니다.

OpenAI API Key는 필요하지 않습니다. `AI 분석` 또는 `AI에게 질문`을 선택하면 프로그램이 Database 계산값, Timeline과 경영일지를 Markdown으로 정리해 Clipboard에 복사하고 ChatGPT를 엽니다.

사용자는 붙여넣을 내용을 확인한 뒤 ChatGPT 입력창에서 전송합니다. 프로그램은 ChatGPT 계정이나 대화 내용을 읽지 않습니다. AI 분석 결과는 원인·강점·약점·개선 우선순위·실행과제·기대효과를 검토하는 참고 자료로 사용하세요.

## 7. PDF 저장

월간 경영보고서는 다음 내용을 Markdown과 PDF로 저장합니다.

- 핵심 KPI와 상태
- 차트와 증감률
- 자동 Insight와 Health Score
- Timeline과 Business Journal
- 경영 시뮬레이션과 미래 예측
- 개선과제와 월간 실행 리뷰
- 선택적 AI 분석 내용

보고서 폴더는 `환경설정 → 저장 위치 → 보고서 폴더 열기`에서 확인할 수 있습니다.

## 8. 환경설정

환경설정에서 다음을 관리합니다.

- 한의원명, 대표자명, 개원일
- 예약률·비급여·신환·재진율·삼진율·LTV 등 KPI 목표
- KPI 주의·위험 알림 기준
- 분석 기간과 일반형·단기형·장기형 프로필
- 감시 폴더와 처리 정책
- 자료·보고서·Database·Backup·환경설정 경로
- 다크모드

기본 설정 파일은 Windows 사용자 폴더의 `.km_ai_consultant` 아래에 저장되며 레지스트리를 사용하지 않습니다. 설정 초기화는 환경설정 정보만 삭제하고 원본 자료·보고서·Database·Backup은 보존합니다.

## 9. 업데이트

1. 프로그램을 종료합니다.
2. 중요한 데이터 폴더를 Backup합니다.
3. Public Repository의 최신 Release EXE를 내려받습니다.
4. SHA-256을 확인합니다.
5. 새 EXE를 실행합니다.

사용자 데이터는 EXE와 분리되어 있으므로 정상 업데이트 시 기존 자료를 그대로 사용합니다.

## 10. 자주 발생하는 오류

### 클립보드에 분석 가능한 이미지가 없다고 나옵니다

`Win+Shift+S`로 다시 캡처한 뒤 프로그램 메인 화면에서 `Ctrl+V`를 누릅니다. Clipboard에 파일 경로나 일반 서식만 있는 경우 이미지로 인식되지 않을 수 있습니다.

### OCR 숫자가 틀립니다

원본 화면을 더 크게 캡처하고 글자 대비를 높여 다시 시도합니다. 검수 표에서 직접 수정한 값을 저장할 수도 있습니다.

### Excel 유형이 다르게 판단됩니다

파일명이 아니라 날짜 셀과 실제 내용을 기준으로 일간·월간·연간을 제안합니다. 저장 전 확인창에서 올바른 유형을 선택하세요.

### PDF 표가 인식되지 않습니다

스캔 PDF는 원본 해상도가 낮으면 OCR 정확도가 떨어질 수 있습니다. 해당 페이지를 선명한 이미지로 캡처해 입력하거나 검수 표를 수정하세요.

### Windows에서 실행을 차단합니다

공식 Release 파일인지와 SHA-256을 먼저 확인합니다. 일치하는 공식 파일이라면 SmartScreen의 `추가 정보 → 실행`을 사용할 수 있습니다. 일부 백신은 별도 예외 등록이 필요할 수 있습니다.

### 분석 결과가 적거나 비교값이 없습니다

해당 기간의 Database 자료가 부족한 상태입니다. 프로그램은 없는 값을 추정하지 않습니다. Data Readiness와 신뢰도를 확인하고 자료를 계속 누적하세요.

## 11. 데이터 보호

프로그램 데이터는 Local PC에만 저장됩니다. 다만 사용자가 AI 분석용 Markdown을 ChatGPT에 직접 붙여넣는 순간 해당 내용은 사용자가 선택한 ChatGPT 서비스로 전달됩니다. 환자 이름, 연락처, 주민등록번호 등 식별정보를 제거한 뒤 사용하세요.

## 12. 참고사항

- OCR 결과는 반드시 확인하세요.
- 통계·Health Score·예측은 경영 참고 자료입니다.
- 최종 의사결정은 사용자가 직접 내려야 합니다.
- AI 답변은 사실과 실제 경영 상황을 대조해 참고용으로 사용하세요.
