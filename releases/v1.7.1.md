## Windows 안내

Code Signing 인증서가 아직 적용되지 않아 SmartScreen 경고가 표시될 수 있습니다. 공식 Release와 SHA-256을 확인한 경우 `추가 정보 → 실행`을 선택할 수 있습니다. 이 EXE는 Microsoft Defender 검사에서 위협 없음 상태를 확인했습니다.
